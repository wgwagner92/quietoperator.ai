# quietoperator.ai — site folder
Upload the contents to the root of the repo. index.html is the showcase (all copy lives in the BUILDS block near the top of its script).
demo/<name>/index.html are single-file demos (Chief of Stuff, Calibrate, Keel, Orbit) that work at any URL path. img/ holds the screenshots.
Demos run on invented sample data and reset on reload. The ARC page uses screenshots only; no copy of the ARC site is hosted here.
