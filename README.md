# quietoperator.ai — site folder
Drop the contents at the root of the host. index.html is the showcase (all copy lives in the BUILDS block).
demo/chief-of-stuff/ is the multi-file demo built for that path. demo/calibrate, demo/keel and demo/orbit are single-file demos that work at any path.
img/ holds the screenshots. Demos run on invented sample data and reset on reload.
